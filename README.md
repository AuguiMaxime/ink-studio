# TRAIT — Studio de tatouage (React + Vite)

Direction blackwork minimaliste : Anton + Work Sans + IBM Plex Mono,
noir/blanc/rouge sang, illustrations linework dessinées à la main.

## Installation
```
npm install
npm run dev
```

## Build de production
```
npm run build
```

Projet de démonstration réalisé dans le cadre d'un portfolio.
Le formulaire de contact simule l'envoi (aucune requête réseau réelle).
